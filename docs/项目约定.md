# 项目约定（GOAT Mall）

> 铁律级约定，动代码/部署前先读这份。修改本文件需同步更新版本号。

## 1. 技术栈（v1.4 定案，勿擅改）

| 层 | 选型 |
|---|---|
| 后端 | PHP 8.3 + Laravel 12 + Octane(Swoole) + Reverb(WS) + Horizon(队列) |
| 数据库 | PostgreSQL 17 + TimescaleDB（行情 hypertable + continuous aggregates）+ PgBouncer |
| 缓存/队列 | Redis 7（独立 DB index：cache/queue/broadcast 分开） |
| 搜索 | Meilisearch |
| C 端 | uni-app (Vue3) — H5 / iOS / Android / 微信小程序 四端同源 |
| PC 后台 | Vue3 + Element Plus |
| 行情/爬虫 | Python 3.12 worker（**独立仓 `goat-collector`**，非本仓代码） |
| 存储 | UCloud UFile（S3 协议）→ 正式期迁 COS/OSS |

## 2. 数据库约定

- **媒体只存对象 key，不存完整 URL**（URL 由 API 层按 `MEDIA_BASE_URL` 配置拼接——换域名只改配置）
- 时序数据全部走 TimescaleDB hypertable + continuous aggregates，禁止手写 K 线聚合任务
- 资金相关表（orders/payments/escrow/bids）必须带状态机 + 幂等键（唯一约束）
- 迁移文件禁止修改已上线的历史迁移，只能新增

## 3. Git 约定

- 分支：`main`（=临时站部署源）← `develop` ← `feature/*` / `fix/*`
- commit 信息中文，格式：`类型: 摘要`（feat/fix/chore/docs/refactor/test）
- **任何凭据/密钥/密码不进仓库**——新增配置项必须同时更新 `.env.example`（占位值）
- `.gitattributes` 不得删除（换行符统一 LF）

## 4. 部署约定（临时站 · 东京 BitsFlow 216.23.112.40，主机名 flat-fire）

- 部署源：push 到 `main` → GitHub Actions → SSH 部署（后续接入）
- 部署打 tag：`deploy-YYYYMMDD-HHMM`
- 回滚：保留最近 5 个版本的 release 目录，软链切换
- 临时站 4G 物理 + 4G swap；全栈常驻服务需评估内存预算（PG `shared_buffers` 压到 512M、Meili 限制内存、Octane 进程数受限）
- 可视化管理：已装**宝塔面板**（管 Nginx 站点 / SSL / cron / 文件 / 监控）；PG17 + TimescaleDB + Redis + Meilisearch 仍**手动装**，Octane 走 systemd（宝塔不接管这些）
- 正式期此机转职**日本行情采集机**（东京出口，Mercari 采集）

## 5. 安全约定

- 支付回调、分账回调：幂等键防重放，非法状态跃迁必须告警
- 上传图片：服务端压缩 + WebP + 动态水印
- 爬虫：显式代理绑定（不走系统代理），代理失联立即熔断停爬，防 IP 裸奔
- 备份：每日 pg_dump + WAL 归档，加密落盘；**每月恢复演练**

## 6. 禁止事项

- 禁止在测试环境之外的任何环境用真实支付渠道
- 禁止把 UFile/PG/Redis 的生产凭据写进任何文档或代码
- 禁止跳过 `docs/踩坑记录.md` 里已记录的坑直接踩第二遍

## 7. 双系统边界（站点 goat-mall ⇄ 采集 goat-collector）

> 2026-11-03 讨论决策：为软著（代码整洁 + 安全）与并行开发，站点与采集**拆成两个独立系统**。

- **站点系统** = `goat-mall`（本仓：Laravel + uni-app + PC 后台）
- **采集系统** = `goat-collector`（独立仓：Python 3.12 worker，图鑑底库 + 行情采集）
- 通信**仅**经三类契约（详见 `docs/架构契约.md`，两仓共用、先读）：① 共享 PG 库 `goat_mall` ② Redis 队列/PubSub ③ 内部 HTTP（admin 触发爬取，HMAC 鉴权）
- **严禁**：Web 层直接 import 采集源码、或持有爬虫源 token / 日本出口 IP；采集器出网 IP 与 Web 层隔离
- 软著可拆两件：「GOAT潮玩交易平台软件 V1.0」（站点）+「GOAT潮玩数据采集软件 V1.0」（采集）
- 双 LLM 路由（CodeBuddy 多 agent）：DeepSeek 做批量生成/脚手架，智谱 GLM 5.3 做中文业务语义/支付竞价精细逻辑与审校；禁止两模型对同一份代码并行改写
