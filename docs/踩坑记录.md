## 环境

### 1. 本机访问 GitHub 必须走 VPN 代理
- 现象：`git ls-remote github.com` 卡死/无输出
- 解法：仓库本地配置 `git config http.proxy http://127.0.0.1:2080`（goat-mall 已配置；凭据走 Windows 凭据管理器缓存）
- 验证：`git ls-remote origin` 有返回即通

### 2. 本机 Chrome 无头不可用（RDP + GPU 环境）
- 现象：Chrome 152/156 无头启动即退出，无输出
- 解法：需要浏览器自动化时用 **Edge 无头 + CDP**（`msedge.exe --headless=new --remote-debugging-port=9222`）+ playwright-core `connectOverCDP`
- 关联：mmacg 嗅探即此路线；`D:/#工作文档/02.合作伙伴/GreatestOfAllToyz/.crawl/crawl.js` 可复用

### 3. Windows 上 .bat 必须纯 ASCII（历史教训，全局适用）
- cmd 按 GBK 解析，中文注释/特殊字符会让整行崩溃
