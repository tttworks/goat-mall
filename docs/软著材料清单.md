### 2. 源程序（前 30 页 + 后 30 页，每页 50 行）

- 总源程序 **12,283 行**（约 246 页 / 每页 50 行），按"超过 60 页交前后各 30 页"提交
- 抽取范围：`app/` + `database/migrations/` + `routes/` + `public/index.php`
- **不要**放入：`vendor/`、`node_modules/`、`config/`（脚手架）、`tests/`（测试代码会被质疑非产品代码）、`docs/`
- 建议排序（体现"接口 → 业务 → 数据"的完整链路）：

| 顺序 | 目录 | 理由 |
|---|---|---|
| 1 | `routes/api.php` | 一页看懂系统功能边界 |
| 2 | `app/Http/Controllers/Api/**` | 接口实现，命名即业务 |
| 3 | `app/Services/**` | 核心业务：认证、图鑑、交易、支付、担保 |
| 4 | `app/Models/**`、`app/Enums/**` | 数据模型与状态机 |
| 5 | `database/migrations/**` | 库表设计证据 |

生成脚本（在 `backend/` 目录执行，输出到 `../docs/copyright/source-all.txt`）：

```powershell
$utf8 = New-Object System.Text.UTF8Encoding($false)
$order = @('routes\api.php') +
  (Get-ChildItem app\Http\Controllers -Recurse -File -Filter *.php | Sort-Object FullName | ForEach-Object { $_.FullName }) +
  (Get-ChildItem app\Services -Recurse -File -Filter *.php | Sort-Object FullName | ForEach-Object { $_.FullName }) +
  (Get-ChildItem app\Models,app\Enums,app\Exceptions -Recurse -File -Filter *.php -ErrorAction SilentlyContinue | Sort-Object FullName | ForEach-Object { $_.FullName }) +
  (Get-ChildItem database\migrations -File -Filter *.php | Sort-Object Name | ForEach-Object { $_.FullName })

$all = foreach ($f in $order) { [System.IO.File]::ReadAllLines($f, [System.Text.Encoding]::UTF8) }
New-Item -ItemType Directory -Force -Path ..\docs\copyright | Out-Null
[System.IO.File]::WriteAllLines("$PWD\..\docs\copyright\source-all.txt", $all, $utf8)
"TOTAL_LINES=$($all.Count)"
```
